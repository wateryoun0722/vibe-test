# PRD: 날씨 앱 (app_weather)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제품명 | 오늘 날씨 어때 |
| 목적 | 도시 이름이나 내 위치로 현재 날씨와 5일 예보를 한눈에 보여준다 |
| 플랫폼 | 웹 브라우저 (데스크톱 + 모바일 반응형) |
| 기술 스택 | HTML / CSS / JavaScript (Vanilla JS) + Bootstrap 5 |
| 데이터 | OpenWeather API (무료 플랜) |
| 서버 | 없음. 정적 파일만으로 동작 |
| 구현 폴더 | `day12/myweather/` |

## 2. 파일 구조

HTML, CSS, JS는 반드시 **파일을 분리**한다.

```
day12/myweather/
├── index.html        # 화면 마크업 (Bootstrap CDN 로드)
├── css/
│   └── style.css     # 커스텀 스타일
└── js/
    ├── config.js     # API 키 (const API_KEY = "...")
    └── app.js        # API 호출, 화면 렌더링, 이벤트 처리
```

- `index.html`에는 인라인 `<style>`, 인라인 `<script>`, `onclick=""` 같은 인라인 이벤트 속성을 쓰지 않는다.
- 스크립트 로드 순서: `bootstrap.bundle.min.js` → `js/config.js` → `js/app.js`
- `config.js`의 API 키는 `day10/index.html`에 있는 OpenWeather 키를 그대로 사용한다. (공개되어도 무방함)

### 외부 라이브러리 (CDN)

| 라이브러리 | 버전 | 용도 |
|---|---|---|
| Bootstrap CSS / JS bundle | 5.3.3 | 레이아웃, 입력창, 버튼, 카드 |
| Bootstrap Icons | 1.11.3 | 검색, 위치, 습도, 바람, 우산, 일몰 등 아이콘 |
| Google Fonts – Noto Sans KR (선택) | - | 본문 폰트 |

## 3. 사용하는 API

공통 파라미터: `appid={API_KEY}`, `units=metric`, `lang=kr`

| 용도 | 엔드포인트 | 주요 파라미터 |
|---|---|---|
| 현재 날씨 (도시) | `https://api.openweathermap.org/data/2.5/weather` | `q={도시}` |
| 현재 날씨 (좌표) | 위와 동일 | `lat={위도}&lon={경도}` |
| 5일 예보 (3시간 간격) | `https://api.openweathermap.org/data/2.5/forecast` | `q={도시}` 또는 `lat`/`lon` |
| 날씨 아이콘 이미지 | `https://openweathermap.org/img/wn/{icon}@2x.png` | `{icon}` = 응답의 `weather[0].icon` |

- 현재 날씨와 5일 예보는 `Promise.all`로 **동시에** 요청한다.
- 한글 도시 이름(예: `서울`)이 검색되지 않는 경우를 대비해, 자주 쓰는 도시는 영문 이름으로 바꿔 요청한다. (예: `서울 → Seoul`, `부산 → Busan`, `제주 → Jeju`, `인천 → Incheon`, `대구 → Daegu`, `대전 → Daejeon`, `광주 → Gwangju`, `울산 → Ulsan`) 매핑에 없는 이름은 입력값 그대로 요청한다.

### 응답에서 사용하는 값

| 화면 항목 | 응답 필드 |
|---|---|
| 도시 이름 | `weather.name`, `weather.sys.country` |
| 현재 기온 / 체감 | `main.temp` / `main.feels_like` |
| 최고 / 최저 | `main.temp_max` / `main.temp_min` |
| 날씨 설명 | `weather[0].description` (한글) |
| 아이콘 | `weather[0].icon` |
| 습도 | `main.humidity` (%) |
| 바람 | `wind.speed` (m/s) |
| 일몰 | `sys.sunset` (Unix 초) + `timezone` (초 단위 오프셋) |
| 기준 시각 | `dt` + `timezone` |
| 강수확률 | 예보 첫 항목의 `list[0].pop` × 100 (%) |
| 5일 예보 | `forecast.list` (3시간 간격 40개) |

## 4. 화면 구성

한 페이지(Single Page)로, 위에서 아래로 다음 순서로 배치한다.

```
┌──────────────────────────────────────────────┐
│ ☁ 오늘 날씨 어때                    [°C][°F] │  ① 헤더
├──────────────────────────────────────────────┤
│ [ 도시 이름 입력          ] [🔍 검색] [📍]   │  ② 검색
│ (오류 메시지 자리)                            │
│ 최근 검색: (서울) (부산) (제주)               │
├──────────────────────────────────────────────┤
│  (아이콘)  📍 서울, KR                        │  ③ 현재 날씨 카드
│            18°                               │
│            맑음 · 체감 17° · 최고 22°/최저 11° │
│                         10월 20일 (월) 14:00 │
├──────────────────────────────────────────────┤
│ [💧 습도] [🌬 바람] [☂ 강수확률] [🌇 일몰]   │  ④ 상세 정보 (4칸)
├──────────────────────────────────────────────┤
│ [화] [수] [목] [금] [토]                      │  ⑤ 5일 예보
│ 아이콘 / 최고° 최저°                          │
└──────────────────────────────────────────────┘
```

### ① 헤더
- 구름 아이콘 + 제목 `오늘 날씨 어때`
- 오른쪽: 단위 전환 토글 `°C` / `°F` (선택된 쪽이 파란 배경)

### ② 검색
- 알약 모양 입력창, placeholder: `도시 이름 (예: 서울, 부산, 제주)`
- `검색` 버튼(파랑, 메인 버튼)과 `📍` 내 위치 버튼(보조 버튼, `aria-label="내 위치 날씨"`)
- 입력창 아래에 오류 메시지 영역 (빨간 글씨, 평소에는 비어 있음)
- **최근 검색** 칩 목록 (최대 5개, 최신순). 칩을 누르면 해당 도시를 다시 검색한다. 최근 검색이 없으면 이 줄을 숨긴다.

### ③ 현재 날씨 카드
- 왼쪽: 원형 배경 안의 날씨 아이콘 (OpenWeather 아이콘 이미지)
- 오른쪽: `📍 도시, 국가코드` / 큰 글씨 현재 기온 / `설명 · 체감 N° · 최고 N° / 최저 N°`
- 오른쪽 위: 기준 시각 `10월 20일 (월) 14:00 기준` (해당 도시 현지 시각)

### ④ 상세 정보
- 4칸 그리드: 습도(%), 바람(m/s 또는 mph), 강수확률(%), 일몰(HH:MM, 현지 시각)
- 모바일에서는 2×2로 배치

### ⑤ 5일 예보
- 5칸 그리드, 각 칸: 요일(`화`) / 아이콘 / `최고° 최저°` (최저는 연한 글씨)
- 모바일에서는 가로 스크롤 없이 5칸 유지 (글자와 아이콘 크기 축소)

## 5. 기능 요구사항

### F1. 도시 검색
- 검색 버튼 클릭 또는 입력창에서 `Enter`를 누르면 검색한다.
- 입력값의 앞뒤 공백을 제거한다. 비어 있으면 요청하지 않고 `도시 이름을 입력해 주세요`를 표시한다.
- 입력창에 다시 입력하면 오류 메시지를 지운다.
- 검색에 성공하면 최근 검색에 추가한다.

### F2. 내 위치 날씨
- `📍` 버튼을 누르면 `navigator.geolocation.getCurrentPosition`으로 좌표를 받아 `lat`/`lon`으로 요청한다.
- 위치 권한을 거부하거나 실패하면 `위치를 가져오지 못했어요. 도시 이름으로 검색해 주세요`를 표시한다.

### F3. 현재 날씨 + 상세 정보 표시
- 3번 항목의 "응답에서 사용하는 값" 표대로 응답 필드를 화면 항목에 채운다. 기온은 **반올림한 정수**로 표시한다.
- 시각(기준 시각, 일몰)은 응답의 `timezone` 오프셋을 적용해 **해당 도시의 현지 시각**으로 표시한다.

### F4. 5일 예보
- `forecast.list`(3시간 간격)를 현지 날짜별로 묶는다.
- **오늘을 제외한 다음 5일**을 표시한다. (데이터가 5일에 못 미치면 있는 만큼만 표시)
- 하루의 최고 기온은 그날 항목들의 `temp_max` 최댓값, 최저 기온은 `temp_min` 최솟값을 쓴다.
- 아이콘은 그날 **12:00(정오)에 가장 가까운 항목**의 아이콘을 쓴다.

### F5. 단위 전환 (°C / °F)
- API는 항상 `units=metric`으로 요청하고, 화면에 표시할 때만 변환한다. 다시 요청하지 않는다.
- °F = °C × 9 / 5 + 32, mph = m/s × 2.237 (소수 첫째 자리까지)
- 기온 전체(현재, 체감, 최고/최저, 5일 예보)와 바람 단위를 함께 바꾼다.
- 선택한 단위는 `localStorage`에 저장하고, 다음 접속 때 복원한다.

### F6. 최근 검색
- 성공한 검색어를 `localStorage`에 최대 5개 저장한다 (최신이 맨 앞, 중복은 맨 앞으로 이동).
- 칩을 누르면 해당 도시를 검색한다.

### F7. 첫 화면
- 최근 검색이 있으면 가장 최근 도시를, 없으면 `서울`을 자동으로 검색해 보여준다.

### F8. 로딩과 오류 처리

| 상황 | 화면 처리 |
|---|---|
| 요청 중 | 검색 버튼에 스피너 표시 + 버튼 비활성화, 카드 영역 살짝 흐리게 |
| 도시 없음 (HTTP 404) | `'{입력값}'을(를) 찾지 못했어요. 도시 이름을 확인해 주세요` |
| 키 오류 (HTTP 401) | `API 키를 확인해 주세요 (js/config.js)` |
| 네트워크 오류 / 기타 | `날씨를 불러오지 못했어요. 잠시 후 다시 시도해 주세요` |

- 오류가 나도 **이전에 보여주던 날씨는 그대로 유지**한다.
- `localStorage` 읽기/쓰기는 `try/catch`로 감싸, 막힌 환경에서도 앱이 동작하게 한다.

| 아이콘 코드 | 상태 | 배경 |

| `01` | 맑음 | `--sun-light` |

### 형태
- 카드: `border-radius: 16~20px`, 흰 배경
- 입력창, 버튼, 칩: 알약 모양 (`border-radius: 999px`)
- 현재 기온: 3rem 이상, 굵게
- 전체 컨테이너 최대 너비: 720px, 가운데 정렬
- 날씨가 바뀔 때 카드가 살짝 나타나는 페이드 효과 (0.3s 이내)

### 반응형
- `md`(768px) 이상: 상세 정보 4칸 한 줄
- `md` 미만: 상세 정보 2×2, 현재 날씨 카드는 아이콘 위 / 정보 아래로 쌓기
- 375px 폭에서 가로 스크롤이 생기지 않아야 한다

## 7. 접근성
- 입력창에 `<label class="visually-hidden">`을 연결한다.
- 아이콘만 있는 버튼(`📍`)에는 `aria-label`을 준다.
- 날씨 아이콘 이미지에는 `alt`로 날씨 설명을 넣는다.
- 오류 메시지 영역은 `role="alert"`로 둔다.
- 단위 토글은 `aria-pressed`로 선택 상태를 표시한다.

## 8. JS 구조 가이드 (`js/app.js`)

```js
// 상태
const state = {
  unit: 'C',          // 'C' | 'F'
  current: null,      // 현재 날씨 응답
  forecast: null,     // 5일 예보 응답
  recent: [],         // 최근 검색 도시 (최대 5)
};

const CITY_MAP = { '서울': 'Seoul', '부산': 'Busan', /* ... */ };

// 함수 목록 (각 함수는 한 가지 일만 한다)
buildUrl(endpoint, params)     // 공통 파라미터를 붙여 URL 생성
fetchWeather(params)           // 현재 + 예보를 Promise.all로 요청, 오류 코드별 처리
searchCity(name)               // 입력값 검사 → 영문 변환 → fetchWeather
searchMyLocation()             // geolocation → fetchWeather
summarizeForecast(list, tz)    // 3시간 예보 → 날짜별 { day, icon, max, min } 5개
renderCurrent()                // 현재 날씨 카드 + 상세 정보
renderForecast()               // 5일 예보
renderRecent()                 // 최근 검색 칩
setUnit(unit)                  // 단위 변경 + 저장 + 다시 렌더링
formatTemp(c) / formatWind(ms) // 단위에 맞춰 표시 문자열 반환
formatLocalTime(unix, tz)      // 현지 시각 'HH:MM' 반환
setLoading(isLoading)          // 로딩 표시
showError(message) / clearError()
loadPrefs() / savePrefs()      // localStorage (try/catch)
```

- 이벤트는 모두 `addEventListener`로 연결한다. 최근 검색 칩은 부모 요소에 이벤트 하나를 걸어 처리한다 (이벤트 위임).
- 상태를 바꾼 뒤 `render*` 함수로 화면을 다시 그린다. 단위 전환은 API를 다시 부르지 않고 렌더링만 다시 한다.

## 9. 완료 기준 (Acceptance Criteria)

- [ ] `index.html`, `css/style.css`, `js/config.js`, `js/app.js`로 분리되어 있다.
- [ ] 첫 화면에서 서울(또는 최근 검색 도시)의 날씨가 자동으로 표시된다.
- [ ] `서울`, `부산`, `제주`, `London`을 검색하면 각각의 현재 날씨와 5일 예보가 표시된다.
- [ ] 없는 도시(예: `asdfgh`)를 검색하면 안내 문구가 나오고, 이전 날씨는 그대로 남아 있다.
- [ ] 빈 입력으로 검색하면 요청하지 않고 안내 문구가 나온다.
- [ ] `📍` 버튼으로 현재 위치의 날씨가 표시되고, 권한을 거부하면 안내 문구가 나온다.
- [ ] °F로 바꾸면 모든 기온과 바람 단위가 바뀌고, 새로고침 후에도 유지된다.
- [ ] 최근 검색이 최대 5개까지 쌓이고, 칩을 누르면 다시 검색된다.
- [ ] 기준 시각과 일몰 시각이 해당 도시의 현지 시각으로 표시된다. (`London` 검색 시 한국 시각과 다름)
- [ ] 375px 모바일 폭에서 가로 스크롤이 없다.
- [ ] 콘솔 오류가 없다.
