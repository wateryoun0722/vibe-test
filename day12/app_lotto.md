# PRD: 로또 번호 생성기 (app_lotto)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 제품명 | 오늘의 행운 번호 (로또 번호 생성기) |
| 목적 | 사용자가 고정 번호와 제외 번호를 지정하면, 조건에 맞는 로또 번호 5세트를 생성해 준다 |
| 플랫폼 | 웹 브라우저 (데스크톱 + 모바일 반응형) |
| 기술 스택 | HTML / CSS / JavaScript (Vanilla JS) + Bootstrap 5 |
| 서버 | 없음. 정적 파일만으로 동작 (`index.html`을 브라우저로 열면 실행) |
| 외부 데이터 | 사용하지 않음 (지난 회차 당첨 번호 노출 기능 **제외**) |

## 2. 파일 구조

HTML, CSS, JS는 반드시 **파일을 분리**한다.

```
day12/
├── index.html        # 화면 마크업 (Bootstrap CDN 로드)
├── css/
│   └── style.css     # 커스텀 스타일 (파스텔 테마, 번호 공, 번호판)
└── js/
    └── app.js        # 상태 관리, 번호판 렌더링, 번호 생성, 복사, 초기화
```

- `index.html`에는 인라인 `<style>`, 인라인 `<script>`, `onclick=""` 같은 인라인 이벤트 속성을 쓰지 않는다.
- `app.js`는 `</body>` 직전에 `defer` 없이 로드하거나, `<head>`에서 `defer`로 로드한다.

### 외부 라이브러리 (CDN)

| 라이브러리 | 버전 | 용도 |
|---|---|---|
| Bootstrap CSS / JS bundle | 5.3.3 | 레이아웃(그리드), 버튼, 카드, 토스트 |
| Bootstrap Icons | 1.11.3 | 아이콘 (클로버, 하트, 금지, 휴지통, 복사, 체크 등) |
| Google Fonts – Jua 또는 Gowun Dodum (선택) | - | 귀여운 한글 제목 폰트 |

## 3. 화면 구성

한 페이지(Single Page)로 구성하며, 위에서 아래로 다음 순서로 배치한다.

```
┌───────────────────────────────────────────┐
│            🍀  오늘의 행운 번호              │  ① 헤더
│        콕콕 찍어두면 알아서 골라줄게요        │
├─────────────────────┬─────────────────────┤
│ ♥ 꼭 넣을 번호 0/5  │ ⊘ 빼줄 번호  0개    │  ② 분할 번호판
│  (1~45 번호판)      │  (1~45 번호판)      │     (모바일: 위/아래로 쌓임)
├─────────────────────┴─────────────────────┤
│ [선택 초기화]  [ ✨ 행운 번호 뽑기 (5세트) ] │  ③ 액션 버튼
├───────────────────────────────────────────┤
│ 뽑은 번호                    [🗑 결과 지우기] │  ④ 결과 카드
│ A  ⓻ ⑫ ⑲ ㉓ ㉛ ㊵                [복사]   │
│ B  ...                            [복사]   │
│ ... (E까지 5줄)                            │
└───────────────────────────────────────────┘
```

### ① 헤더
- 원형 배경 안의 클로버 아이콘 (`bi-clover` 또는 대체 아이콘)
- 제목: `오늘의 행운 번호`
- 부제: `콕콕 찍어두면 알아서 골라줄게요`

### ② 분할 번호판 (고정 번호 / 제외 번호)
- Bootstrap 그리드: `row` > `col-12 col-md-6` 2개 → **데스크톱은 좌우 분할, 모바일은 위아래**.
- 각 패널은 둥근 카드(점선 테두리)이며, 안에 1~45 번호 버튼을 **7열 그리드**로 배치한다.

| 구분 | 왼쪽 패널 | 오른쪽 패널 |
|---|---|---|
| 제목 | ♥ 꼭 넣을 번호 | ⊘ 빼줄 번호 |
| 테마 색 | 핑크 | 보라 |
| 카운터 배지 | `N / 5` | `N개` |
| 최대 선택 수 | **5개** | **39개** |
| 선택된 번호 스타일 | 핑크 배경 + 흰 글자 | 보라 배경 + 흰 글자 + 취소선 |

### ③ 액션 버튼
- **선택 초기화** (보조 버튼, 알약 모양): 고정 번호, 제외 번호 선택을 모두 해제한다. **생성 결과는 유지**한다.
- **행운 번호 뽑기 (5세트)** (메인 버튼, 핑크, 알약 모양, 가로로 넓게): 5세트를 새로 생성해 결과 카드에 표시한다. 기존 결과는 새 결과로 교체된다.

### ④ 결과 카드
- 카드 제목: `뽑은 번호`
- 오른쪽 위: **🗑 결과 지우기** 버튼 (빨간 글씨, 작은 알약 모양)
- 각 세트 한 줄 구성: `세트 라벨(A~E)` + `번호 공 6개(오름차순)` + 오른쪽 끝 `복사` 버튼
- 세트 사이 구분선: 점선
- 결과가 없을 때(빈 상태):
  - 웃는 얼굴 아이콘 + `아직 뽑은 번호가 없어요` 안내
  - `결과 지우기` 버튼은 숨긴다

## 4. 기능 요구사항

### F1. 번호판 선택 / 해제
- 번호를 클릭하면 선택, 다시 클릭하면 해제한다 (토글).
- 고정 번호는 최대 5개까지 선택할 수 있다. 6번째를 누르면 선택되지 않고 토스트로 안내한다: `꼭 넣을 번호는 5개까지 고를 수 있어요`
- 제외 번호는 최대 39개까지 선택할 수 있다. 초과하면 토스트로 안내한다: `최소 6개 번호는 남겨둬야 해요`
- **상호 배타**: 한쪽 패널에서 선택된 번호는 반대쪽 패널에서 흐리게(opacity 0.3) 표시되고 클릭할 수 없다 (`disabled`).
- 선택할 때마다 카운터 배지를 즉시 갱신한다.

### F2. 번호 생성 (5세트)
- `행운 번호 뽑기` 버튼을 누르면 5세트를 생성한다.
- 각 세트 생성 규칙:
  1. 고정 번호를 모두 포함한다.
  2. 나머지 칸(6 − 고정 번호 개수)은 `1~45` 중 **고정 번호와 제외 번호를 뺀 후보**에서 중복 없이 무작위로 뽑는다.
  3. 6개를 **오름차순 정렬**한다.
- 5세트끼리는 가능한 한 **서로 다르게** 만든다. 같은 조합이 나오면 다시 뽑는다 (세트당 최대 100회 재시도). 후보가 부족해 서로 다른 조합을 만들 수 없으면 중복을 허용하고 토스트로 안내한다: `고를 수 있는 번호가 적어서 같은 조합이 있을 수 있어요`
- 무작위 함수는 `crypto.getRandomValues`를 우선 사용하고, 없으면 `Math.random`을 쓴다.
- 결과에서 **고정 번호 공은 핑크 링(테두리)** 으로 강조한다.

### F3. 세트별 복사
- 각 세트 오른쪽의 `복사` 버튼을 누르면 해당 세트 번호를 클립보드에 복사한다.
- 복사 형식: `7, 12, 19, 23, 31, 40` (쉼표 + 공백으로 구분)
- 복사 방식: `navigator.clipboard.writeText()`를 우선 사용하고, 실패하면 숨긴 `<textarea>` + `document.execCommand('copy')` 방식으로 대체한다.
- 복사에 성공하면 버튼을 1.5초 동안 초록색 `✓ 복사됨`으로 바꾼 뒤 원래대로 되돌린다.
- 두 방식이 모두 실패하면 토스트로 안내한다: `복사하지 못했어요. 번호를 직접 선택해 복사해 주세요`

### F4. 결과 지우기
- `결과 지우기` 버튼을 누르면 결과 목록을 비우고 빈 상태 안내를 표시한다.
- 번호판 선택(고정/제외)은 유지한다.

### F5. 선택 초기화
- `선택 초기화` 버튼을 누르면 고정 번호와 제외 번호 선택을 모두 해제하고 번호판, 카운터를 갱신한다.
- 생성 결과는 유지한다.

### F6. 초기 상태
- 페이지를 처음 열면 고정/제외 선택은 없고, 결과는 **빈 상태**다 (자동 생성하지 않음).
- 데이터 저장(localStorage 등)은 하지 않는다. 새로고침하면 초기 상태로 돌아간다.

### 형태와 효과
- 번호판 셀: 원형, 7열 그리드, 비선택 시 연회색 배경. 마우스를 올리면 `scale(1.12)`로 살짝 커짐 (transition 0.12s)
- 결과 번호 공: 지름 36px 원형, 굵은 글씨
- 버튼: 알약 모양(`border-radius: 999px`)
- 카드: `border-radius: 16~20px`, 번호판 패널은 1.5px 점선 테두리
- 전체 컨테이너 최대 너비: 720px, 가운데 정렬
- 결과 번호 공이 생성될 때 살짝 튀어오르는 애니메이션(선택 사항, 0.3s 이내)

### 반응형
- `md`(768px) 이상: 번호판 좌우 분할
- `md` 미만: 번호판 위아래 배치, 결과 한 줄에 공 6개와 복사 버튼이 들어가도록 공 크기를 30px로 축소

## 6. 접근성
- 번호판 셀은 `<button type="button">`으로 만들고, `aria-pressed`로 선택 상태를 표시한다.
- 잠긴 셀은 `disabled` 속성을 준다.
- 복사 버튼에는 `aria-label="A세트 복사"` 형태의 라벨을 준다.
- 토스트는 Bootstrap Toast를 쓰고 `role="status"`로 둔다.

## 7. JS 구조 가이드 (`js/app.js`)

```js
// 상태
const state = {
  fixed: new Set(),     // 꼭 넣을 번호 (최대 5)
  excluded: new Set(),  // 빼줄 번호 (최대 39)
  results: [],          // number[][] — 생성된 5세트
};

const MAX_FIXED = 5;
const MAX_EXCLUDED = 39;
const SET_COUNT = 5;

// 함수 목록 (각 함수는 한 가지 일만 한다)
renderBoards()        // 두 번호판 + 카운터 렌더링
toggleNumber(type, n) // 'fixed' | 'excluded' 토글 + 제한 검사
generateSet()         // 규칙에 맞는 1세트 생성 (number[])
generateSets()        // 서로 다른 5세트 생성 → state.results
renderResults()       // 결과 카드 / 빈 상태 렌더링
copySet(index, btn)   // 클립보드 복사 + 버튼 피드백
clearResults()        // 결과 지우기
resetSelection()      // 선택 초기화
getBallClass(n)       // 번호대별 공 CSS 클래스 반환
showToast(message)    // Bootstrap 토스트 표시
```

- 이벤트는 모두 `addEventListener`로 연결한다. 번호판은 패널 컨테이너에 클릭 이벤트 하나를 걸어 처리한다(이벤트 위임).
- DOM은 상태를 바꾼 뒤 `render*` 함수로 다시 그린다.

## 8. 완료 기준 (Acceptance Criteria)

- [ ] `index.html`, `css/style.css`, `js/app.js` 세 파일로 분리되어 있다.
- [ ] 첫 화면에서 결과는 빈 상태이며 `아직 뽑은 번호가 없어요`가 보인다.
- [ ] 고정 번호는 5개까지만 선택되고, 초과하면 토스트가 뜬다.

- [ ] `결과 지우기`는 결과만 비우고 선택은 유지한다.
- [ ] `선택 초기화`는 선택만 비우고 결과는 유지한다.
