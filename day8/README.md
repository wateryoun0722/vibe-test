# Day 8 - CSS Flexbox

## 파일 목록
- `cssFlexExam01.html` : Flexbox로 로그인 박스를 화면 정중앙에 배치하는 예제

## 배운 내용
- `display: flex` : 자식 요소를 가로/세로로 정렬
- `flex-direction` : 정렬 방향 (`row` 가로, `column` 세로)
- `justify-content` : 주축 방향 정렬
- `align-items` : 교차축 방향 정렬
- `border-radius` : 모서리 둥글게
- `border-bottom` : 입력창 밑줄만 표시
